\section{Attack Prompts}
\label{app:prompts}

The paraphrase, translation, and regeneration tactics use the templates below.
Placeholders in angle brackets are filled from the configuration file. The
templates are recorded here because a paraphrase attack is only reproducible if
its instruction is.

\begin{quote}
\small
\textbf{Instruction paraphrase.} Rewrite the following passage so that the meaning, entities, numbers, and order of ideas are preserved. Change the wording and sentence structure. Return only the rewritten passage.\\
\textbf{Passage.} \texttt{<source>}
\end{quote}

\begin{quote}
\small
\textbf{Discourse paraphrase.} You are rewriting a passage from a longer document. Preserve every factual claim. You may reorder sentences and merge or split them. Return only the rewritten passage.\\
\textbf{Context.} \texttt{<surrounding paragraphs>}\\
\textbf{Passage.} \texttt{<source>}
\end{quote}

\begin{quote}
\small
\textbf{Style normalisation.} Rewrite the passage in a plain, human register: contractions where natural, no em dashes, no stock transitions, no filler. Preserve meaning and length. Return only the rewritten passage.\\
\textbf{Passage.} \texttt{<source>}
\end{quote}

\begin{quote}
\small
\textbf{Back-translation control.} Translate the passage into \texttt{<pivot language>}. Return only the translation.
\end{quote}

\begin{quote}
\small
\textbf{Cross-lingual generation.} (1) Translate the passage into \texttt{<pivot language>}. (2) Rewrite the translation in \texttt{<pivot language>}, preserving every factual claim. (3) Translate the result back into English. Return only the final English passage.\\
\textbf{Passage.} \texttt{<source>}
\end{quote}

\begin{quote}
\small
\textbf{Regeneration.} Write a new passage from the instruction below. Keep the same topic, audience, and approximate length. Return only the new passage.\\
\textbf{Instruction.} \texttt{<prompt or source>}
\end{quote}
