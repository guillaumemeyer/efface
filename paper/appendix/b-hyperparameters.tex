Seven tactics have a continuous intensity and are swept at three points; the five discrete tactics are evaluated at one setting. The intensity names a request to the attacker model or a parameter of the transformation; it is not an achieved edit rate measured on the output.

\paragraph{Search settings.}
Beam width $B = 8$ and maximum depth $3$, giving $1{,}884$ ordered chains before intensities are considered. Semantic floor $\tau = 0.80$ with tolerance $\epsilon = 0.02$; minimum detectable difference $0.05$ absolute removal rate; search split fraction $0.6$ with seed $20261117$; three stochastic repetitions per document; Holm correction within each depth; per-document $\alpha = 0.05$ and corpus operating point at $1\%$ false-positive rate. The main sweep and the chain search use each tactic's default intensity; the depth-one intensity sweep uses the values in Table~\ref{tab:hyper}.

\paragraph{Detector settings.}
Scheme parameters are those used at generation: the MarkLLM SynthID configuration recorded in the run manifest, with temperature $0.7$, top-$p$ $0.9$, and $400$ new tokens per document. The scheme's logits processor requires top-$k \le 0$, so decoding uses top-$p$ sampling only. Detection threshold $\alpha = 0.05$ per document, and the corpus operating point at $1\%$ false-positive rate.
